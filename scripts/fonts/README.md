# Catalog fonts

Noto Sans Regular and SemiBold are embedded into the generated PDF for Turkish
character support. They are build inputs, not browser assets; catalog generation
does not download fonts or require operating-system fonts.

Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

The SIL Open Font License is included in `OFL.txt`.
